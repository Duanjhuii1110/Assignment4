# Assignment4 · 喜鹊谋杀案式的新闻档案

以《喜鹊谋杀案》的叙事装置（童谣计数 / 缺失的一章 / 双层叙事 / 元叙事）重构孙小果案报道的十页翻页式档案网站。

- 线上地址：https://duanjhuii1110.github.io/Assignment4/
- 技术形态：单文件 HTML（`index.html`），零依赖、零构建，GitHub Pages 由 GitHub Actions 自动部署。
- 操作方式：方向键 ← → / 滚轮 / 触摸滑动 / 点击左右半屏翻页；底部「批注 OFF/ON」开关可切换编者批注层。
- 叙事结构：十页对应童谣 One for sorrow … Ten for a bird you must not miss；第七页为 CHAPTER MISSING（2007 年再审改判所依据的"重大立功"专利材料）。
- 内容原则：仅使用公开判决书与权威媒体公开报道中的事实，不能核实的细节一律不写。
